# ZODIACO

Programa simple en Python para identificar el signo zodiacal según la fecha de nacimiento.

## ¿Qué hace?
- Pide la fecha de nacimiento del usuario.
- Calcula el signo zodiacal.
- Muestra un mensaje breve relacionado con ese signo.

## Ejecutar

```bash
python zodiaco.py
```

O pasando una fecha directamente:

```bash
python zodiaco.py 1998-05-15
```

## Ejemplo

```bash
$ python zodiaco.py
Ingresa tu fecha de nacimiento (YYYY-MM-DD): 1998-05-15
Tu signo zodiacal es: Tauro
Mensaje: Eres una persona estable, perseverante y muy sensible a la belleza.
```
